# fell-and-sell-ct
Personal Fell &amp; Sell Cheat Table Collection for Cheat Engine

Because there were no trainers/cts I created my own. Free of use for anyone as long as I'm willing to update it.

Features:
- PlayerStats (Data structure included for dissecting)
- Max Health
- Current Health
- Health Regen Rate
- Max Stamina
- Current Stamina
- Stamina Regen Rate
- Stamina Drain Sprint
- Stamina Drain Jump
- Stamina Drain Attack
- Stamina Drain Block
- Stamina Regen Delay
- Max Mana
- Current Mana
- Mana Regen Rate
- Attack Speed Modifier
- Current Base Scale
