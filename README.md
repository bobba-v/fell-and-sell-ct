# Fell & Sell — Cheat Engine Table

A working **Cheat Engine table (CT)** for **Fell & Sell**.

I created this table because I couldn't find a working trainer or Cheat Engine table for the game, so I decided to make one myself.

Feel free to use it, modify it, and learn from it. As long as I'm still willing and able to update it, I'll try to keep it working with newer versions of the game.

## Features

### Player Stats

Includes a `PlayerStats` data structure for easier inspection and dissecting.

Currently available:

* **Max Health**
* **Current Health**
* **Health Regen Rate**
* **Max Stamina**
* **Current Stamina**
* **Stamina Regen Rate**
* **Stamina Drain — Sprint**
* **Stamina Drain — Jump**
* **Stamina Drain — Attack**
* **Stamina Drain — Block**
* **Stamina Regen Delay**
* **Max Mana**
* **Current Mana**
* **Mana Regen Rate**
* **Attack Speed Modifier**
* **Current Base Scale**

## Requirements

* [Cheat Engine](https://www.cheatengine.org/)
* A compatible version of **Fell & Sell**

## Installation

1. Download the latest `.CT` file from the **Releases** section, or clone/download this repository.
2. Start **Fell & Sell**.
3. Open the Cheat Engine table.
4. Attach Cheat Engine to the game's process.
5. Enable the entries you want to use.
